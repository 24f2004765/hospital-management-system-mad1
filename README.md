# hospital-management-system-mad1

Hospitals need efficient systems to manage patients, doctors, appointments, and
treatments. Currently, many hospitals use manual registers or disconnected
software, which makes it difficult to manage records, avoid scheduling conflicts,
and track patient history.

Built using `Flask`, `Jinja2`, `HTML`, `CSS`, and `SQLite`, this app is supposed
to help manage appointments and diagnosis history for both doctors and patients.
